Mevi VPN

Mevi VPN is a modern VPN client designed to manage multiple VPN configurations and automatically switch between them when the current connection becomes unavailable.

Instead of manually reconnecting or searching for a working server, Mevi VPN can monitor available configurations and use another connection when necessary.

«Your configurations. One client.»

---

Features

- Import custom VPN configurations
- Import subscription links
- Manage multiple VPN profiles
- Automatic failover between configurations
- Fast one-tap connection
- Connection availability checks
- Server and profile management
- Automatic selection of an available connection
- Clean and minimal interface
- Designed for self-hosted and third-party VPN infrastructure

---

Automatic Failover

One of the main features of Mevi VPN is automatic configuration switching.

If the active VPN configuration stops working, the application can check other available configurations and switch to a working connection.

This reduces the need to manually change servers when network conditions change.

---

Configuration Management

Users can keep multiple VPN configurations inside one application.

Configurations can be organized by:

- Server
- Country
- Protocol
- Profile
- Subscription

This makes Mevi VPN suitable both for personal use and for users managing larger VPN infrastructures.

---

Supported Connections

Mevi VPN is designed to work with modern proxy and VPN technologies.

Depending on the application core and configuration format, supported connections may include:

- VLESS
- VLESS Reality
- VMess
- Trojan
- Shadowsocks
- Hysteria2
- Subscription-based configurations

Support for additional protocols may be added in future releases.

---

How It Works

1. Add a VPN configuration or subscription.
2. Mevi VPN imports available connection profiles.
3. Select a server manually or enable automatic selection.
4. Connect to the VPN.
5. If the current connection becomes unavailable, Mevi VPN can attempt another available configuration.

---

Use Your Own Infrastructure

Mevi VPN is a VPN client.

The application can be used with:

- Self-hosted VPN servers
- Personal VPN infrastructure
- Compatible VPN providers
- Subscription-based VPN services

Mevi VPN does not require users to use a specific VPN provider.
